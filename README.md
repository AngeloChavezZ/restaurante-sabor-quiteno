# 🍽️ Sabor Quiteño - Página Web de Restaurante

Página web de un restaurante ecuatoriano, con menú, sección informativa y contacto. Proyecto de práctica de desarrollo web front-end con diseño responsive.

🔗 **Verla en vivo:** [angelochavezz.github.io/restaurante-sabor-quiteno/restaurante.html](https://angelochavezz.github.io/restaurante-sabor-quiteno/restaurante.html)

## 🧰 Tecnologías

- HTML5
- CSS3 con diseño responsive (media queries)
- Publicada con GitHub Pages

## 📄 Secciones

- **Menú** — platos típicos con descripción y precio
- **Nosotros** — presentación del restaurante
- **Contacto** — ubicación y WhatsApp
